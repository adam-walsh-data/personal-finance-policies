# Personal Finance Aggregator

A personal project under development to consolidate account information and transactions from supported financial institutions for the account holder's own financial overview.

## Status

This project is in development. Bank connectivity and automated synchronisation are not yet active. No bank credentials or financial account data are collected by this website.

The intended design is read-only: the application will request access only to account information and transaction history needed for the personal overview. It is not intended to initiate payments or move money.
